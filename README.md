# 1RM 계산기

웨이트 트레이닝 기록과 1RM 추정을 중심으로 만든 React 기반 피트니스 웹앱입니다.  
반복 중량 계산, 기록 저장, PR 추적, 훈련 분석까지 한 번에 확인할 수 있도록 구성했습니다.

## 무엇을 할 수 있나요?

### 1. 1RM 계산기
- 무게와 반복 횟수를 입력하면 1RM을 즉시 추정합니다.
- 아래 5가지 공식을 함께 비교할 수 있습니다.
  - Epley
  - Brzycki
  - Lombardi
  - Mayhew
  - O'Conner
- 계산 후 트레이닝 존(60~100%)도 바로 확인할 수 있습니다.

### 2. 목표 반복 중량 계산
- 아래 5대 바벨 리프트 중 하나를 선택합니다.
  - 벤치프레스
  - 오버헤드프레스
  - 스쿼트
  - 데드리프트
  - 바벨로우
- 1RM과 목표 반복 횟수를 입력하면 해당 반복 수에 맞는 **예상 훈련 중량**을 계산합니다.
- 리프트별로 서로 다른 반복 비율 테이블을 사용해 더 현실적인 결과를 제공합니다.
- 결과에는 다음 정보가 포함됩니다.
  - 예상 중량
  - 1RM 대비 비율
  - 짧은 설명 문구

예시:
- 벤치프레스 1RM `130kg`
- 목표 반복 횟수 `8회`
- 예상 중량 `약 105kg`

### 3. 대시보드
- 마지막 1RM
- 주간 볼륨
- 연속 운동일
- 누적 볼륨
- 종목별 PR 보드
- 목표 진행률

### 4. 분석 화면
- 기록 데이터를 바탕으로 볼륨과 1RM 흐름을 확인할 수 있습니다.
- 최근 변화 추세를 빠르게 훑어볼 수 있도록 차트 중심으로 구성되어 있습니다.

### 5. 프로필 / 설정
- `kg / lb` 단위 전환
- 다크 / 라이트 모드
- 로컬 데이터 백업/복원

## 계산 방식

### 1RM 계산
아래 공식을 사용합니다.

| 공식 | 특징 |
|---|---|
| Epley | 가장 널리 쓰이는 표준 추정 |
| Brzycki | 저반복 구간에 강한 편 |
| Lombardi | 비교적 보수적인 추정 |
| Mayhew | 연구 기반 공식 |
| O'Conner | 단순하고 직관적인 선형 모델 |

### 목표 반복 중량 계산
- 반복 횟수 범위: `1~15회`
- 계산 방식: 리프트별 `%1RM` 매핑 기반
- 반올림 방식:
  - `kg` 사용 시: `2.5kg` 단위 반올림
  - `lb` 사용 시: `5lb` 단위 반올림

즉, 이 기능은  
`1RM → 목표 반복 횟수에서 사용할 만한 실제 훈련 중량`  
을 빠르게 얻기 위한 용도입니다.
